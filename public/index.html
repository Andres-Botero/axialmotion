Approach

How we like to build

  1. 01

    Start from the job, not the screen.

    A visit, an invoice, a missed referral. The product should make that job shorter.

  2. 02

    Ship something an operator can use on Monday.

    Fewer settings, more defaults. If it only works in a demo, it is not done.

  3. 03

    Keep the surface small.

    One place for the work. Related pieces should talk to each other.
